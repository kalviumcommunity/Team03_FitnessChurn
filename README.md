# Team03_FitnessChurn

# Fitness Customer Retention Analytics

## Problem Statement

A fitness application stores workout completion logs, streak history, and subscription renewals, but product teams cannot identify which engagement behaviours actually influence long-term retention.

---

## Project Overview

This project aims to analyze customer engagement data from a fitness application to identify the factors that influence customer retention. By performing data analysis and building predictive models, the project will help product teams understand user behaviour and make data-driven decisions to improve long-term retention.

---

## Objectives

Analyze customer engagement patterns.
Identify factors influencing customer churn and retention.
Build a machine learning model to predict customer churn.
Develop an interactive dashboard to visualize insights and predictions.

---
